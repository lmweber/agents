# Project instructions for Codex

This project contains three related folders:

- `package/`: R package source code
- `analyses/`: repository containing analysis scripts
- `paper/`: manuscript files

When working in this project:

- Treat this directory as the project/workspace root.
- Do not search outside this directory.
- Do not inspect parent directories such as `~` or outside directories such as `~/Documents`, `~/Desktop`, or `~/Downloads`.
- You may read files within the project/workspace for context.
- Do not modify files unless explicitly asked to or given permission.
- Do not create commits, amend commits, reset, rebase, merge, tag, or push.
- Leave all changed files unstaged unless explicitly asked.
- At the end of any task, list any suggested files to change. For coding related tasks, also suggest a commit message, but do not commit. If you have been given permission to change files, list any files that have been changed.
